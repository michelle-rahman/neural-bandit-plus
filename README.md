# NeuralBandit++: Stabilizing Importance-Weighted Updates

COMS 4726 Deep Learning for Data Science, Final Project

Reproduction and extension of "A Neural Networks Committee for the
Contextual Bandit Problem" (Allesiardo, Féraud, Bouneffouf, 2014).

**Extension:** importance-weight clipping and Adam/AdamW in place of plain SGD,
evaluated on Forest Cover Type under abrupt and gradual drift.
